Connect to your TV

Same Wi-Fi as this computer, network debugging on. Everything runs through CleanYourTV's own scripts over ADB: no root, no cable.

TV address

Find it on the TV under Settings → Network & Internet. Port 5555 unless you add :port.

First time on this TV

  1. Settings → Device Preferences → About → press OK on Build seven times.
  2. Back → Developer options → USB debugging on. Turn on Network/ADB debugging too if it is there.
  3. Press Connect, then accept Allow USB debugging? on the TV within two minutes.

Chromecast with Google TV and the Google TV Streamer only offer Wireless debugging with a pairing code: pair once with Google's adb and run adb tcpip 5555 first.

When you are done

Turn USB debugging off on the TV, then confirm the port is closed. Anyone on your network can otherwise ask the TV for a debug session.

Debloat

Pick the list for your TV, untick anything you use, then disable the rest. A recovery record is written before the first change, so Restore puts the TV back exactly as it was.

Home screen

Replace the ad-filled stock home with CleanYourTV's launcher (about 532 KB), then style it with a theme. Themes push without a rebuild.

Launcher

Builds the APK, installs it, makes it Home and rolls back if Home does not land on it. Needs JDK 17 and the Android SDK on this computer (ANDROID_HOME); the first build downloads Gradle and takes a few minutes.
